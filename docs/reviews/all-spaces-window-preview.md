# 跨桌面窗口发现：实现与验证记录

日期：2026-10-23。状态：开发与自动化检查已进行，真实跨桌面交互验收未完成；PR 保持草稿，不应据此发布。

## D01：范围与产品行为

- 结论：全局预览默认「全部桌面」，可以在设置或预览页头切换到「当前桌面」。旧设置缺少新键时也采用全部桌面，这是本次确认的新行为，并非旧实现已经完整枚举。
- 应用专属预览、Workspace 应用分组预览和 Dock 预览不受全局范围筛选影响；它们继续查找该应用／分组的全量窗口。
- 当前桌面模式仍保留其他桌面的已发现窗口数量与展开入口。数量是当前已发现的有效窗口，不保证不响应 AX 或使用自定义窗口实现的应用绝无遗漏。
- 其他桌面、最小化、隐藏与归属未知分别表达。离屏预览不能当成实时内容；保留现有缓存或图标与标题降级，不扩大缓存期限和容量。
- 跨桌面卡片先支持定位窗口；到达窗口前禁用关闭、最小化和缩放，避免在未确认目标时操作错误窗口。

## D02：窗口索引与性能边界

- 原因：旧 `getAllWindows()` 实际为 `.optionOnScreenOnly` 加 AX 最小化窗口，遗漏其他桌面的普通窗口；本机 `AXWindowNumber` 属性普遍不可用。
- 实现：共享 `WindowSystemIdentity` 动态读取 `_AXUIElementGetWindow`，缺失时退回原属性。`WindowSpaceSnapshot` 通过可选 SkyLight 读取活动桌面与窗口归属；无结果时保留未知，不猜桌面编号。
- 按需扫描在专用串行队列完成，合并 AX 标准窗口和 CG 全量列表中有明确其他桌面归属的普通层窗口。真实 ID 去重，拒绝无明确归属的 CG 离屏辅助 surface。没有真实 ID 的普通 AX 窗口不伪造截图身份。
- 扫描期间先返回当前可见窗口，并显示查找状态；扫描完成通知面板刷新。缓存 2 秒，应用激活／启动／退出与 Space 变化时失效；过期扫描结果按 revision 丢弃，停止监控时取消扫描。
- 保留后台监控的 CG 可见窗口轻量路径，不为全部桌面增加后台连续截图。现有截图预算、刷新兴趣和隐私限制继续适用；未做硬件 GPU 或 WindowServer 能耗实测。
- 这些私有接口是可选兼容能力，不承诺所有 macOS 12+ 版本或 Mac App Store 支持。缺失时降级，不应宣称全量发现已获跨版本认证。

## D03：窗口选择与失败闭环

- 跨桌面只允许精确 ID 候选；禁止失败后按标题、几何或逐窗口探测提升同应用其他窗口。窗口操作查询同样遵循该限制。
- 选择后进行有界采样，要求目标窗口实际位于 CG 可见前列，且 AX 焦点 ID 为同一窗口；不能只凭应用已激活或接口返回成功。
- 跨桌面动画等待上限为 1.5 秒，目标连续稳定 5 个样本后提前结束；实际目标到达与稳定性仍须实机验收。
- 面板隐藏后切窗失败会显示本地化错误提示。Dock ViewModel 不再把失败返回成成功。
- 枚举未完成或权限不足时不执行「只有一个窗口直接切换」，避免将局部列表误当成全量。刷新列表时按 ID 替换选择对象，避免保留旧桌面状态。

## D10：其他 Space 窗口聚焦的实测根因与修复

日期：2026-10-26。覆盖 D09 中「前置后重新查询精确 AX 候选」的方案。

- 复现：Dock 预览点击 VS Code 其他 Space 的窗口 895／975 仍报「Unable to focus window」。补充诊断日志后得到 `Other-space target has no exact AX candidate. axWindows=1`：前置请求返回成功，但 1.5 秒内应用只暴露当前 Space 的窗口 896。
- 实测（/tmp 临时脚本，已清理）：窗口 895／975 位于第二块屏幕的 Space 6／4，当前为 19。`kAXWindows` 不含其他 Space 窗口；仅 `_SLPSSetFrontProcessWithOptions` 返回 0 但不切换 Space；仅对枚举到的元素 AXRaise 也不切换；前置 + key window 事件记录 + AXRaise 组合后目标上屏、Space 切换成功。
- 修复：`WindowSystemIdentity.remoteAXWindow` 按远程令牌枚举应用 AX 元素，只接受窗口 ID 精确相等者；`requestFront` 增加 key window 事件记录；随后沿用 `focus` 的 AXRaise 与 CG／AX 校验。找不到精确元素或前置失败即返回失败，不猜其他窗口。
- 性能：枚举上限 1000，实测全量扫描 VS Code 约 87 ms、飞书约 37 ms，在串行 `focusQueue` 上执行。按 (pid, windowID) 缓存元素，命中时校验元素仍指向同一窗口 ID，聚焦失败时清除，容量上限 64，加锁。
- 体感：切换前后未出现中间 Space，系统切换动画约 400–480 ms；用户反馈有轻微卡顿，原因未定位（疑为其他因素），暂不处理。
- 已知限制：依赖私有接口（`_AXUIElementCreateWithRemoteToken`、SkyLight 前置与事件记录），系统更新后可能失效，失效时报失败而非误聚焦；元素 ID 超过扫描上限的应用会找不到目标。
- 验证：`make build`、`make test-unit`（278 项，7 跳过，0 失败）通过；用户实机确认 VS Code 跨桌面点击功能正常。新逻辑依赖真实多桌面环境，未补单元测试；其他应用类型未逐一验证。
