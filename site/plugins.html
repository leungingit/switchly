Dock 预览插件 API

插件为 Dock 预览中的应用卡片叠加自定义控件，例如悬停 Apple Music 时显示的播放控制。插件用 JavaScript 编写，运行在内嵌的 JavaScriptCore 中，只返回一棵声明式 UI 树，由 Switchly 用 SwiftUI 绘制。插件拿不到绘图上下文，也不能直接联网或读取任意文件；需要文件时只能申请只读目录权限。

当前支持 apiVersion 1 和 2，新插件应使用 2。完整中文契约见 公开 API 参考，机器能力清单位于 capabilities.json，manifest 校验规则位于 manifest.schema.json。SDK 与 CLI 已以本仓库零依赖源码包提供，但尚未发布到 npm。

内置 Music 插件（com.switchly.music-controls）在 Dock 预览中的实际效果。

概览

Dock 预览 ── PluginOverlayView（渲染 UI 树，处理点击）
                │
        PluginRuntime（每插件一个 JSVirtualMachine，私有串行队列）
                │  ctx.storage + 已授权的 media/weather/fs
        MediaBridge / 宿主天气快照 / 只读文件根

插件目录
  开发源：../switchly-plugins/plugins/<id>/
  未来预装制品：.build/Plugins/<id>/
  用户安装：~/Library/Application Support/Switchly/Plugins/<id>/
        ├── manifest.json
        ├── main.js            # 单文件 bundle
        ├── assets/            # 可选，受路径与包预算限制
        └── locales/en.json, zh-Hans.json   # 可选，供 ctx.t()

官方插件开发源在外部仓库 switchly-plugins，路径为 ../switchly-plugins/plugins/<id>/。第一阶段只安装用户选择的本地目录；内置插件 ID 不能被用户包覆盖。用户插件更新会重新要求授权。

包限制为 32 MiB、最多 1024 个条目、manifest.json 最多 256 KiB、入口最多 2 MiB，并禁止包根或包内任意符号链接。version 只要求非空，以兼容历史 "1"，不强制 SemVer。

manifest.json

{
  "id": "com.example.music-controls",
  "name": { "en": "Music Controls", "zh-Hans": "音乐控制" },
  "version": "1.0.0",
  "apiVersion": 2,
  "matches": ["com.apple.Music"],
  "permissions": ["media.nowPlaying", "media.control"],
  "entry": "main.js",
  "refreshInterval": 1,
  "settings": [
    { "key": "showCover", "default": true,
      "title": { "en": "Show album cover", "zh-Hans": "显示专辑封面" } }
  ]
}
字段类型必填说明
idstring是反向域名，匹配 ^[A-Za-z0-9]+(\.[A-Za-z0-9-]+)+$，全局唯一。
name{语言: 文本}是按 en、zh-Hans 等键本地化，设置页展示。
summary{语言: 文本}否一句话说明，显示在设置页插件名后的「?」悬浮提示中；缺省时只列权限。
versionstring是非空插件自身版本；不强制 SemVer，兼容历史 "1"。
apiVersionint是宿主支持 1–2；范围外拒绝加载。2 起可返回 scene 节点、声明 select / number 设置。
matches[bundleID]是目标应用 bundle ID，不能为空；悬停这些应用的 Dock 图标时才会运行。
permissions[string]是请求的能力，不能重复，见权限；未知字符串导致 manifest 解码失败。
entrystring是入口相对路径；不能为空、以 / 开头或含 ..。
refreshInterval秒否大于 0 且不超过 86400；实际重绘下限 1 秒，不可见时零调用。
settings[对象]否设置 key 和选项 value 必须唯一，值通过 ctx.settings 传入。支持 toggle、select、number。
fsRoots[对象]条件声明 fs.read 时必须提供非空根数组；每项含 id、path、本地化 summary。
defaultEnabledboolean否只影响内置插件的初始启用状态；缺省为 true。

effect 目前只有 "hideWindowPreviews"：该选项打开时，宿主隐藏窗口缩略图，只显示插件组件。

settings.type 缺省为 toggle；select 使用 options: [{value,title}]，默认值必须属于选项；number 可设置 min、max、step。

运行时约定

插件 bundle 必须把入口注册到全局：

globalThis.__switchlyPlugin = {
  async render(ctx)            { return [ /* { slot, node } */ ]; },   // 返回 null / [] 表示无叠层
  async onAction(ctx, id, value) { /* 用户操作 */ },                    // 可选
};

两个函数可同步、async 或抛异常；返回值经 JSON.stringify 传回宿主。本仓库 SDK 的 definePlugin() 会注册同样形态。

项目行为
隔离每插件独立 JSVirtualMachine + JSContext，在私有串行队列执行。
可用全局console.log/info/debug/warn/error（写入日志，带 plugin=<id>，单条截断 500 字符并限速）、setTimeout/clearTimeout（每插件最多 32 个，卸载时清除）、原生 Promise。
不存在fetch、XMLHttpRequest、文件系统、子进程。
超时Dock 预览生产路径单次 render/onAction 软超时 1 秒：JSC 没有公开的硬中断 API，迟到结果被丢弃；连续 3 次超时自动停用该插件。
异常脚本错误或非法输出记入日志，该卡片回落为无叠层。
生命周期Dock 预览出现时挂载；面板关闭或切换应用时卸载并清除定时器；下次渲染重建 JS 环境。授权变化也会重建。

ctx 对象

每次调用传入的只读快照：

成员说明权限
ctx.app{ bundleID, pid, name, lastActiveAt }；lastActiveAt 是 Unix 秒或 null。无
ctx.window{ windowID, title }。title 已截断到约 40 字符，完整标题不会交给插件；该应用无窗口时 windowID 为 0。无
ctx.locale首选语言标识，如 "zh-Hans-CN"。无
ctx.settings{ [key]: boolean | string | number }：manifest 默认值被用户保存的值覆盖，且只含已声明的 key。设置项可声明 "type": "select"（options: [{ value, title }]，值为字符串）或 "type": "number"（min、max、step），默认开关为 boolean。无
ctx.reduceMotion系统「减少动态效果」是否开启。scene 会由宿主自动静帧；插件可据此跳过动画阶段。无
ctx.t(key)从 locales/<语言>.json 取文案，回退 en，再回退 key 本身。无
ctx.invalidate()请求宿主尽快重新 render。无
ctx.storage插件私有 Promise JSON 存储：get(key): Promise<JSON|null>、set/remove/clear(): Promise<void>。key 最多 256 字节，单值最多 64 KiB，单插件总计最多 1 MiB。无
ctx.media.nowPlaying()返回 Promise<NowPlaying | null>：playing、title、artist、album、position、duration、progress(0–1)、liked、canLike。应用未运行、无当前曲目或尚未授权自动化时为 null，且不会拉起目标应用。media.nowPlaying
ctx.media.togglePlayPause() / next() / previous()播放控制，返回 Promise。media.control
ctx.media.setLiked(on)喜欢／取消喜欢（Music 的 favorited）。media.control
ctx.media.library.pickRandom(keywords)在资料库里按曲风关键词随机挑一首（无匹配则任意一首），返回 Promise<{ persistentID, title, artist, bpm, matchedGenre } | null>，不播放。media.library
ctx.media.library.play(persistentID) / pause()播放指定曲目／暂停。脚本由宿主生成，插件只给出关键词与曲目 ID。media.library
ctx.weather.current()同步返回宿主已获取的天气 { condition, temperature, wind, source }。method 始终存在；未授权 weather.current、在线天气关闭、未配置、失败或结果过期时都返回 null。插件不会因此联网。数据需要 weather.current
ctx.fs只读根内文件：list、stat、readText、scan、isLocked，均返回 Promise。只有授权 fs.read 后才存在；不能选择绝对路径。fs.read

未授权的 ctx.media 方法和整个 ctx.fs 不存在。天气方法例外：ctx.weather 始终存在，但无授权时返回 null。专辑封面不经 JS 传递：由宿主按需读取并绘制，仅当 UI 树包含 image 的 {artwork:true} 且插件有 media.nowPlaying 授权。

onAction(ctx, id, value)

点击 button 时 value 为 null；toggle 为 1（开）或 0（关）；slider 为 0–1 的数值。按钮的悬停、按下、焦点状态由宿主本地绘制，不往返 JS；点击按钮不会触发切窗。

声明式 UI

render 返回 null、[] 或 [{ slot, node }, …]。解码即校验：未知类型、未知枚举值、必填字段缺失都会使整次输出被拒绝。尺寸、圆角、间距、材质均取宿主设计令牌，插件不能传颜色值或像素尺寸。

权限模型

权限字符串作用状态
media.nowPlaying注入 ctx.media.nowPlaying()，允许宿主为 image{artwork} 读取封面可用（仅 Apple Music）
media.control注入播放控制与 setLiked可用（仅 Apple Music）
media.library注入 ctx.media.library（挑选／播放／暂停资料库曲目）可用（仅 Apple Music）
weather.current注入 ctx.weather.current()，读取宿主已获取的天气快照（Open-Meteo，无需密钥）可用（需用户在插件设置中开启在线天气，默认关闭）
fs.read注入 ctx.fs，只读访问 manifest 的 fsRoots 根内文件可用；必须显式声明根并取得用户授权
window.focus聚焦窗口可声明但未实现；宿主不注入 API
appleScript:<bundleID>未来由宿主提供的预置脚本模板可声明但未实现；宿主不注入 AppleScript API
  • 内置插件：按声明的权限默认启用，用户可关闭。
  • 用户插件：默认关闭；用户在「设置 → 权限 → 插件」查看权限清单并确认后才启用。运行时只获得「声明 ∩ 已确认」的权限。
  • 更新新增权限：保持“尚未允许”且不注入，直到用户再次确认；授权变化会重建 JS 环境。
  • 系统授权：Music 的 Apple Events 自动化权限由宿主申请，首次使用时 macOS 弹窗；未授权前不渲染叠层。插件只能选择命令，从不提供脚本。
  • 隐私边界：插件不能直接联网、启动子进程、读取截图或任意文件；文件只能经 fs.read 的根和路径检查读取。窗口标题仅给截断形式。
  • 本地存储：ctx.storage 按插件隔离，key 256 字节、单值 64 KiB、总量 1 MiB，由宿主管理持久化，不暴露文件路径。

SDK、CLI 与插件源

SDK 与 CLI 位于本仓库的 packages/plugin-sdk/、packages/plugin-cli/，均为零外部依赖源码包。当前没有发布到 npm，下面的包名只在本地工作区或插件仓库自身链接后使用。

# 查看机器能力清单
node packages/plugin-cli/bin/switchly-plugin.js api describe --json

# 校验插件目录
node packages/plugin-cli/bin/switchly-plugin.js validate <插件目录>

# 验证后原样复制到 .build/Plugins/<id>/
node packages/plugin-cli/bin/switchly-plugin.js build <插件目录>

# 零模板依赖创建一个可立即验证的插件
node packages/plugin-cli/bin/switchly-plugin.js create <目标目录>

build 不执行 TypeScript 转译或 JavaScript 打包，也不会伪造完整编译器。正式插件需先在自身构建流程中形成单入口 JavaScript。create 会生成最小 manifest、入口和双语 locale，并立即运行验证；CLI 发布包的 prepack 会把能力清单与 manifest Schema 复制到包内 contract/，因此 api describe 不依赖宿主仓库路径。

最小示例：Music 控制条

在 ../switchly-plugins/plugins/com.example.demo/ 开发，校验后用安装器选择本地目录；用户插件默认关闭，确认权限后才运行。

// manifest.json
{ "id": "com.example.demo", "name": { "en": "Demo" }, "version": "0.1.0",
  "apiVersion": 2, "matches": ["com.apple.Music"],
  "permissions": ["media.nowPlaying", "media.control"],
  "entry": "main.js", "refreshInterval": 1 }

// main.js
globalThis.__switchlyPlugin = {
  async render(ctx) {
    const np = await ctx.media.nowPlaying();
    if (!np) return [];
    return [{ slot: "center", node: { type: "surface", material: "glass", children: [
      { type: "vstack", spacing: "xs", align: "center", children: [
        { type: "marquee", value: np.title },
        { type: "text", value: np.artist, style: "caption" },
        { type: "hstack", spacing: "m", children: [
          { type: "button", id: "prev",   symbol: "backward.fill", label: ctx.t("Previous") },
          { type: "button", id: "toggle", symbol: np.playing ? "pause.fill" : "play.fill",
            label: ctx.t(np.playing ? "Pause" : "Play"), size: "l" },
          { type: "button", id: "next",   symbol: "forward.fill",  label: ctx.t("Next") },
          { type: "toggle", id: "love", symbolOn: "heart.fill", symbolOff: "heart",
            isOn: !!np.liked, label: ctx.t("Love") },
        ] },
      ] },
    ] } }];
  },

  async onAction(ctx, id, value) {
    if (id === "toggle")        await ctx.media.togglePlayPause();
    else if (id === "next")     await ctx.media.next();
    else if (id === "prev")     await ctx.media.previous();
    else if (id === "love")     await ctx.media.setLiked(value === 1);
    ctx.invalidate();
  },
};

调试：先在「偏好设置 → 常规」开启「写入本地日志文件」（默认关闭），日志位于 ~/Library/Logs/Switchly/Switchly.log，按 plugin=<id> 过滤。常见失败：Plugin render output rejected（UI 树违反 schema 或限制）、Plugin call timed out（超过 1 秒软超时）、Plugin did not register（未设置 __switchlyPlugin）。
